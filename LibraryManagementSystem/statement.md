# PROBLEM STATEMENT
Managing books and student records manually in a library often leads to errors, misplaced information, difficulty in tracking issued books and inefficient record management. There is a need for a simple, reliable and digital solution that can store book details, maintain student records, track issued and returned books and provide accurate information instantly.

# SCOPE OF THE PROJECT
The scope of this project includes:
- Adding, storing and managing book records.
- Registering students and maintaining their details.
- Issuing books to students with validations.
- Returning books and updationg availability.
- Viewing stored records of books and students.
- Preventing invalid operations such as Duplicate IDs or issuing unavailable books.

The system uses a menu - based Python interface suitable for small libraries, academic labs or basic digital record systems.

# TARGET USERS
- Librarians 
- Students
- Small Educational Institutions
- Anyone who needs a lightweight book-record management system
# HIGH LEVEL FEATURES
- Book Management (Add, View)
- Student Management (Register, View)
- Issue / Return book functionality
- Real-time quantity updates
- Duplicate-ID protection
- Validation for incoreect inputs
- Simple text-based interface for easy usage
