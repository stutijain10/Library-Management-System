# 📚 LIBRARY MANAGEMENT SYSTEM
A Python-based Library Management System designed to manage books, students and book-issue operations using a clean, menu-driven interface.
This project is developed as part of the **VITyarthi - Build your own project** requirement under the *PYTHON ESSENTIALS* Course.

---

## 📌 OVERVIEW
This system allows a librarian or user to manage the essential operations of a library such as adding books, registering students, issuing books, returning books and listing stored records.
The project is built using object-oriented programming concepts and simple data structures to ensure clarity and ease of understanding.

---

## 🚀 FEATURES

### Book Management
- Add books
- Prevent Duplicate Book IDs
- View all books

### Student Management
- Register students
- Prevent Duplicate Student IDs
- View all students

### Book Issue And Return
- Issue books with validation
- Return books and updates the quantity
- Prevent issuing unavailable or already issued books

### Validation And Error Handling
- Incorrect quantity handling
- Missing book/student detection
- Duplicate issuance protection
